# Listing Stager — Copy SOP

## Core Rules
- One clear CTA per email
- Natural, concise language
- No fake personalization
- Clean opt-out path in sequence
- Keep wedge messaging distinct

## Personalization Heuristics
Use 1 concrete signal only:
- market/location context
- recent listing/brand signal
- relevant workflow pain point

Avoid overfitting or fabricated context.

## Variant Testing (Controlled)
Test one variable at a time:
- Subject line
- Opening line
- CTA wording

Do not test multiple major variables simultaneously in early ramp.

## Stop Conditions for Copy
Pause variant if:
- negative sentiment spikes
- complaint appears
- reply floor underperforms for 2 windows

## Compliance Guardrails
- Respect unsubscribes immediately
- Ensure suppression is enforced before next send
- Keep record of copy variants used per campaign
