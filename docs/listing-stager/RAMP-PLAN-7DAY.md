# Listing Stager — 7-Day Ramp Plan (Conservative)

Timezone: EST (America/New_York)
Send window: Mon–Fri, 9:00 AM–4:00 PM

## Volume by Day (per inbox)
- Day 1: 10
- Day 2: 10
- Day 3: 20
- Day 4: 20
- Day 5: 30
- Day 6: 30
- Day 7: 30

## Promotion Criteria
Move to next tier only if all pass:
- Bounce < 2%
- No complaint/spam signals
- Reply floor not breached

## Hold/Regression Rules
- If bounce >= 2%: hold tier
- If bounce >= 3%: pause affected inbox
- If complaint/spam signal: immediate pause
- If reply floor missed twice: hold and investigate

## Resume Criteria After Pause
- Root cause identified and fixed
- QA test sends re-verified
- Lead/copy corrections documented
- Explicit resume approval recorded
