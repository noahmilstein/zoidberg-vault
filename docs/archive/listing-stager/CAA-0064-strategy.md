# CAA-0064 — Listing Stager Cold Outreach Strategy (Approved)

Status: Approved by Noah (2026-03-02)

## 1) ICP Priority
1. Real Estate Agents (primary)
2. Brokerages (secondary)
3. Photographers (tertiary)

Rationale: fastest path to closes and clearest pain at agent level.

## 2) Core Offer by ICP
- Agents: faster listing velocity via better visuals with low operational lift.
- Brokerages: agent-level consistency and brand quality control at scale.
- Photographers: overflow partner / white-label fulfillment path.

## 3) CTA by ICP
- Agents: “Want me to mock one active listing so you can judge quality?”
- Brokerages: “Open to a 15-min pilot plan for 5 agents?”
- Photographers: “Want to test a partner workflow on 2 shoots this month?”

## 4) KPI Targets (Initial)
- Open rate: 45%+
- Reply rate: 8%+
- Positive reply rate: 2.5%+
- Booked call rate: 1%+

Rule: if below target after 300 sends per wedge, revise wedge materially.

## 5) Daily Volume Caps
- Warmup period: no campaign sends
- Week 1 post-warmup: 20 emails/inbox/day
- Week 2 post-warmup: 30 emails/inbox/day
- Week 3+: 40–50 emails/inbox/day only if inbox health remains strong

## 6) Winner Rule
Cadence: evaluate every 7 days.
Primary metrics: positive reply rate + booked-call rate.

Rule:
- Minimum sample size per wedge: 300 sends
- Kill wedge if performance is <60% of top performer
- Reallocate volume: 70% winner / 30% challenger tests
