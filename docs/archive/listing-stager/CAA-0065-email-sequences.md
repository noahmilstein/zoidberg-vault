## Campaign settings recommendations
- One wedge per campaign per inbox (clear attribution).
- Keep domains/inboxes healthy before scaling.
- Use plain-text first; minimal links/images.
- Add unsubscribe language where required by compliance settings.

## Review checklist for approval (CAA-0065 exit criteria)
1. Messaging tone approved
2. Offer/CTA fit approved per ICP
3. Personalization fields finalized
4. Compliance text confirmed
5. Send timing/cadence approved
