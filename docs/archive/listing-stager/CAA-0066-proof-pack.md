## 1) Wedge Proof Assets

### A) Agent Wedge

#### A1) Before/After Listing Example (Template 1)
**Scenario:** Empty living room listing underperforming in click-through.

**Before (raw state):**
- Empty room photo
- No furnishing context
- Hard for buyer to estimate layout/use

**After (staged output):**
- Furnished room layout in modern style
- Preserved room geometry/windows
- Listing presentation becomes move-in imaginable

**Safe proof language:**
- Improves presentation clarity for buyers browsing listings.
- Helps agents test upgraded visuals without a physical staging cycle.
- Can be run on active listings with low operational lift.

#### A2) Before/After Listing Example (Template 2)
**Scenario:** Empty primary bedroom in mid-tier listing.

**Before:**
- Unfurnished bedroom
- Weak emotional hook in gallery

**After:**
- Furnished bedroom with cohesive style
- Better visual context for room scale/function

**Safe proof language:**
- Turns empty space into a more understandable room narrative.
- Supports faster listing-ready visual refresh cycles.

#### A3) Sample Mock Output Deliverable (Agent)
- Original photo
- Staged variant(s)
- 1–2 sentence style explanation
- Optional revision request line

**Send text:**
