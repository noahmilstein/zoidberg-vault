# 2026-02-25 — Simply Sauna Growth Engine (MVP Outbound)

## Strategic Decisions (Confirmed)

- Focus first on **B2B Rentals (wedding/event venues)** as primary spearhead channel.
- Goal is not full funnel automation — goal is **initial replies / curiosity**.
- Noah handles qualification + closing once reply occurs.
- Do NOT overengineer CRM or funnel modeling at MVP stage.

## CRM Reality (Validated via Coding Agent)

- Single `contacts` table (no accounts table).
- Channel segmentation exists via `contacts.type`:
  - b2c
  - b2b_str
  - b2b_event
  - b2b_retreat
  - b2b_other
- Funnel stage stored in `contacts.status` (global per contact).
- Source attribution exists (`source`, `sourceDetail`, UTM fields).
- Sequence system + enrollments already implemented.
- No strict stage transition matrix; admin can set any status.
- Idempotent contact upsert by email already implemented.

Conclusion: No CRM schema redesign required for MVP.

## Outbound Architecture Decision

- Use **Instantly (Done-For-You email setup)** for outbound sending.
- Do NOT use main domain (`info@simply-sauna.com`) for cold outreach.
- Outbound domain: `simplysaunaevents.com`
- Inboxes created:
  - partnerships@simplysaunaevents.com
  - hello@simplysaunaevents.com
- Replies forward to main inbox.
- 5 emails/day per channel (Rental + Install), weekdays only.

## API Key Governance

- Instantly API key stored as Convex env var: `INSTANTLY_API_KEY`.
- Scoped minimally (no all:all).
- Intend to rotate key after MVP validation (key pasted in Slack considered exposed).

## Cron Design Direction (MVP)

Daily (weekdays only):
- Generate 5 rental leads (type=b2b_event, source=cold_outreach).
- Generate 5 install leads.
- Upsert contact in CRM.
- Push to Instantly campaign.
- On reply: set status=contacted, create task, send Slack DM to Noah.

No further automation.

## Philosophy Reinforced

- Move fast, do not overengineer.
- Centralize intelligence in Zappa.
- Instantly = execution engine only.
- CRM = system of record.
- Progressive privilege escalation over time.
